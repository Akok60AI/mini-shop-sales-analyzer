
# Mini Shop Sales Analyzer

A Python project that analyzes shop sales data and presents useful business insights.

## Features
- Calculates total sales and revenue
- Summarizes quantities sold by product
- Identifies the best-selling product
- Shows revenue for each product
- Creates a bar chart to compare product revenue

## Technologies Used
- Python
- Pandas
- Matplotlib

## How It Works
The program processes sample shop sales data, calculates revenue, prints a sales report, and visualizes revenue by product.

## Project Goal
This project demonstrates beginner-level Python programming, data analysis, and data visualization skills.
